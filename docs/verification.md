# 验证说明

## 自动测试

`npm run check`：15 项测试全部通过，TypeScript 严格检查与生产构建通过。

覆盖目录标题、YAML frontmatter、代码围栏、正文搜索、路径校验、唯一文件名、多行原文保存、防抖、保存期间继续编辑、并发保存、写入失败重试、外部修改保护、冲突副本、100 张卡片数据完整性和 CodeMirror CRLF 保留。

文件生命周期集成测试运行实际插件代码，但 Vault 使用内存替身，不能替代真实界面测试。

## 实机验证

2026-10-29，在 macOS、Obsidian 1.14.4 中验证：

| 场景 | 结果 |
| --- | --- |
| 新增命令与按钮 | 新卡片位于顶部，自动聚焦，可直接粘贴 |
| 编辑与保存 | 原地编辑后正文精确落盘，立即关闭并重开后内容完整 |
| 页面复用 | 重复执行打开命令只保留一个卡片页面 |
| 复制 | 使用真实系统粘贴验证，正文与源文件逐字一致 |
| 删除与恢复 | 文件进入 Vault 本地回收站，移回后视图自动恢复 |
| 目录导航 | 标题实时同步，点击滚动定位与高亮一致 |
| 高度一致 | 空卡片查看/编辑均约 117.90px；多行卡片均约 531.90px；缩短内容后两种模式同步缩小 |

高度数值取决于主题、字体和窗口，验证的是同一内容在两种模式之间高度一致。

实测发现并修复：YAML 属性误识别为标题、底部卡片无法滚到目标位置、编辑/查看切换高度变化。使用自动添加 frontmatter 的其他插件时，应在其设置中排除卡片目录。
